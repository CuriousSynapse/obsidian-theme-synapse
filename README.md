# Synapse

## Install

1. Copy this entire `obsidian-theme` folder into your Obsidian vault at `.obsidian/themes/`.
2. Rename the copied folder to `Synapse` if desired. The resulting path should be `<your-vault>/.obsidian/themes/Synapse/`.
3. In Obsidian, open **Settings → Appearance → Themes**, refresh the list if necessary, then select **Synapse**.

## Contents

- `manifest.json` — standard Obsidian theme metadata
- `theme.css` — native Obsidian CSS variables and selectors

There are no scripts, external assets, build steps, or React/Vite dependencies. The theme provides corresponding light and dark palettes, with the dark palette tuned directly to the supplied screenshot.
